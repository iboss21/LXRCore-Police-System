## Item Overview

The system uses three categories of items:

| Category | Description |
|---|---|
| **Core LEO Items** | Physical tools carried on duty (badge, rope, handcuffs, etc.) |
| **Physical Documents** | Paper items generated by game actions (warrants, citations, reports) |
| **Evidence Items** | Evidence bags created during investigation |
| **Wearable / Badge Items** | Attachable badges and belt equipment |

## VORP

VORP manages items through the **`vorp_inventory`** database table. Run the following SQL **once** against your game database to register all items:

```sql
-- ══════════════════════════════════════════════════════════════
-- LXR Police System — VORP Item Registration
-- Run once in your game database (e.g. vorp_inventory DB)
-- ══════════════════════════════════════════════════════════════

-- Core LEO Items
INSERT IGNORE INTO `items` (`name`, `label`, `limit`, `can_remove`, `type`, `usable`, `weight`, `desc`)
VALUES
  ('lawman_badge',          'Lawman Badge',            1,  1, 'item', 1, 100,  'Official law enforcement badge'),
  ('temp_deputy_badge',     'Temporary Deputy Badge',  1,  1, 'item', 0, 100,  'Temporary deputization badge'),
```
